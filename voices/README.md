# Próbki głosu

Wrzuć tu nagranie głosu, który asystent ma sklonować (XTTS v2), i ustaw jego nazwę w `.env` (`VOICE_FILE`).

- format `.wav` (lub `.ogg`), 6–30 sekund czystej mowy, bez muzyki i szumu,
- najlepiej własny głos albo głos osoby, która **wyraziła zgodę** na jego użycie.

Pliki z tego folderu nie trafiają do repozytorium (`.gitignore`).
Głos można zmienić w trakcie działania komendą „zmień głos <nazwa pliku>”.
